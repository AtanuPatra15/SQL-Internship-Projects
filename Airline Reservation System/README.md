✈️ Airline Reservation System
📌 Project Overview
The Airline Reservation System is a MySQL database project developed to manage airline operations efficiently. It stores and manages information related to airports, flights, passengers, bookings, tickets, and payments while maintaining data integrity using SQL constraints, stored procedures, functions, triggers, views, and advanced SQL queries.

🎯 Objectives
Manage airport information.
Store flight schedules.
Maintain passenger records.
Handle ticket bookings.
Manage payment records.
Generate reports using SQL queries.
Ensure data consistency with database constraints and triggers.
